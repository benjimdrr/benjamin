# Anglais One

Carnet de vocabulaire anglais qu'on remplit et révise à plusieurs.

## Utiliser l'appli

L'appli fonctionne comme une page web partagée en direct :

**👉 Lien de l'appli : https://claude.ai/code/artifact/3d46d0a9-23c7-4ab6-b8d9-edbc27d7a9fc**

Envoie ce lien à tes amis. Tout le monde qui l'ouvre voit la même liste de mots, en temps réel :
- ajouter un mot (avec plusieurs traductions possibles),
- modifier ou supprimer un mot,
- réviser avec le quiz (anglais → français, français → anglais, ou mélange),
- suivre un classement commun des scores de quiz.

Rien ne se perd : les mots et les scores sont sauvegardés sur le serveur de l'appli, pas seulement dans le navigateur. Pas besoin de recommencer à chaque visite.

## Fichier source

`anglais-one.html` contient le code source de l'appli (une seule page HTML/CSS/JS). Il est publié tel quel comme "Artifact" Claude, ce qui lui donne accès à une base de données partagée en temps réel entre tous les amis qui ouvrent le lien.

Si le lien ci-dessus change (republication), mets-le à jour ici.
